# Connector portability

## Proven connector

HaasOnline TradeServer is the first execution connector proven through the MCP-based integration boundary in laboratory and production environments.

## Additional engines

The surrounding approach is connector-oriented, but this repository does not claim that other production connectors already exist.

An additional execution engine can be assessed only when:

- it exposes suitable supported APIs or protocols;
- licensing permits the intended integration;
- authentication, security and operational constraints are known;
- test and acceptance criteria can be defined;
- implementation and validation are funded.

## Commercial boundary

Target-engine discovery, connector design, implementation and validation are paid delivery activities.

No public adapter contract, interface schema, command map or executable connector is provided.
